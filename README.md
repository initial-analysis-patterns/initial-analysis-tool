# marimo-pm
Marimo notebooks for process mining

## Getting started

This project uses [uv](https://docs.astral.sh/uv/) for Python and dependency management.
To get started:

1. Sync the environment.

   ```bash
   uv sync
   ```

2. Open a notebook in edit mode:

   ```bash
   uv run marimo edit exploratory-tool.py
   ```

   Or run it as a read-only app:

   ```bash
   uv run marimo run exploratory-tool.py
   ```
